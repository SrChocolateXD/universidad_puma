# plataforma academica - universidad-puma

<!-- DESCRIPCION -->
Este proyecto corresponde al desarrollo de una plataforma web para la gestion de estudiantes y cursos la aplicacion utiliza la arquitectura basada en servicios para separar la gestion de estudiantes y cursos

<!-- tecnologias utilizadas -->
- Node.js
- Express.js
- MySQL
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

<!-- estructura -->

PA3_universidad_puma
|_ servicio-estudiante
|_ servicio-curso
|_ index.html
|_ style.html
|_ README.md


<!-- Funcionalidades -->

--> Gestión de estudiantes

- Registrar estudiantes.
- Listar estudiantes.
- Buscar estudiantes.
- Actualizar estudiantes.
- Eliminar estudiantes.
--> Gestión de cursos

- Registrar cursos.
- Listar cursos.
- Buscar cursos.
- Actualizar cursos.
- Eliminar cursos.

--> Base de datos

La aplicación utiliza MySQL para almacenar la información de:

- Estudiantes
- Cursos
